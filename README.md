# Clinic Management API (Demo)

Technical demo of a backend REST API built with Django REST Framework, intended for portfolio and learning purposes.

## Overview

This project demonstrates core backend concepts such as:
- RESTful API design
- Authentication and authorization using JWT
- Role-based access control
- Business logic separation
- Relational data modeling

The application models a simplified clinic management system, allowing patients to schedule appointments, doctors to manage their schedules and access medical records, and administrators to manage system users.

## Project Status

This project is under active development.

It is intended as a **technical demonstration**, not as a production-ready system.

More detailed documentation will be added as development progresses.
